# Игра МЕМО

Данны проект является реализацией настольной игры МЕМО для развития памяти. 
Нужно запоминать и находить одинаковые пары.

## О проекте
Мемо-игра с трекингом взгляда через WebGazer и распознаванием эмоций с помощью FaceAPI. 
Игрок проходит 3 раунда, в каждом нужно найти 12 пар карточек.

## Технологии
- JavaScript
- WebGazer.js
- FaceAPI.js
- HTML/CSS
- JSZip и html2canvas

## Запуск проекта
1. Клонировать репозиторий
```bash
git clone https://github.com/dolgayapolina/MemoryGame.git
```

2. Перейти в папку проекта 
```bash
cd MemoryGame
```

3. Запустить локальный сервер
```bash 
python -m http.server 8000
```

## Прохождение игры
1. Введите ID
2. Прочитайте правила
3. Пройдите калибровку
4. Игра начнется автоматически 
5. Находите пары одинаковых карточек
6. После прохождения 3 раундов пройдите опрос и сохраните результат

## Структура проекта
```
├── images/               # Изображения карточек
├── mediapipe/            # MediaPipe для WebGazer
├── models/               # Модели для FaceAPI
├── webgazer/             # Библиотека WebGazer
├── game.html             # Главная страница
├── calibration.js        # Калибровка взгляда
├── game_script.js        # Логика игры
├── registration.js       # Регистрация
├── results.js            # Экспорт результатов
└── style_game.css        # Стили
```
